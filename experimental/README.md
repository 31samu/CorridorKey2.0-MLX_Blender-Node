# CorridorKey 2.0 experimental Windows build

[Download the experimental Blender extension](corridorkey_mlx_compositor-0.4.3-experimental.zip?raw=true) and install it in Blender 5.3 or later. In the add-on preferences, click **Set Up CorridorKey** to download the NVIDIA runtime and models.

I'm looking for testers with Windows and an NVIDIA RTX 30-series GPU or newer. Follow the [setup and test instructions](Setup.md) and include the relevant log if something fails.
